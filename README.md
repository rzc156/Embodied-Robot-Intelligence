# Embodied-Robot-Intelligence
A research-grade textbook and engineering handbook on embodied robot intelligence, covering robotics foundations, manipulation, locomotion, loco-manipulation, VLA, world models, humanoid control, agentic robotics, and generalist embodied AI. 中文描述： 面向具身机器人智能的研究级教材与工程手册，系统覆盖机器人数学基础、操作、运动控制、loco-manipulation、VLA、世界模型、人形机器人、Agentic Robotics 与通用具身智能。
